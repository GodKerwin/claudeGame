# 天机残卷 — 游戏改进设计文档

**日期：** 2026-05-29  
**范围：** 7项改进，涵盖Bug修复、移动端适配、属性系统、职业重设计

---

## 背景

当前游戏存在以下问题：
1. 跨章节出现的 NPC 被永久标记为"已对话"导致卡关
2. 未竟之事面板中"?"字符在中文字体下渲染细长
3. 提示系统缺乏实用性，玩家仍频繁卡关
4. 无移动端支持，三栏布局在小屏幕上完全不可用
5. 属性值在角色创建后不再变化，对游戏过程影响有限
6. 职业天赋与初始属性重复强化相同方向，设计冗余
7. 各职业间差异度不足，体验趋同

## 一、Bug 修复

### 1.1 NPC 对话锁定（软卡关）

**根本原因：** `sceneStore` 中的 `seenDialogues: string[]` 跨章节共用，格式为 `npcId:dialogueId`。`npc_wujue` 等 NPC 在多章出现时，第一章已看过的对话在第二章被永久标记为已完成。

**修复方案：**
- 将对话记录键格式改为 `ch{n}:{npcId}:{dialogueId}`（例：`ch1:npc_wujue:first_meet`）
- `sceneStore` 中章节转换时无需清空，因为键已自动按章节隔离
- 修改 `Game.tsx` 中生成/查找已读对话的逻辑，拼接当前章节前缀
- 修改 `saveEngine.ts` 确保存档格式向后兼容：加载旧存档时，若 `seenDialogues` 中的键不包含 `ch` 前缀，自动迁移为 `ch1:` 前缀

**受影响文件：**
- `src/store/sceneStore.ts`
- `src/pages/Game/Game.tsx`（lines 126-135）
- `src/engine/saveEngine.ts`

### 1.2 未竟之事"?"字符细长

**根本原因：** `Noto Serif SC` 中文字体对 ASCII 标点字符宽度压缩，导致"?"渲染过窄。

**修复方案：**
```tsx
// 修改前
<span className="text-ink/30 hover:text-gold/50 cursor-help ml-1">?</span>

// 修改后
<span className="font-sans inline-block min-w-[1em] text-center text-ink/30 hover:text-gold/50 cursor-help ml-1">?</span>
```

**受影响文件：** `src/components/layout/RightPanel.tsx`（line 93）

### 1.3 提示系统重写

**根本原因：** 当前提示仅检查 flags/items，不使用属性上下文；回退文本完全通用；不提供位置指引。

**重写原则：**
- 每条提示规则增加属性感知：属性不足时提示"你的XX属性不足，可尝试寻找替代路线"
- 每条提示包含具体地点或NPC指引，不再只说"去探查"
- 按职业天赋提供差异化提示（`ctx.talent` 已在 HintContext 中，但当前未使用）
- 每章至少 15 条有意义的规则，覆盖主线和分支卡点
- 回退文本改为根据当前章节给出最优先下一步

**受影响文件：** `src/engine/hintEngine.ts`（完整重写）

## 二、移动端适配

### 布局策略

- **桌面端（≥ 768px）：** 保持现有三栏布局完全不变
- **移动端（< 768px）：** 全屏单列 + 底部标签栏

### 底部标签栏设计

```
┌─────────────────────────────────┐
│          故事内容区域            │  ← 当前激活面板全屏显示
│                                 │
│                                 │
├─────────────────────────────────┤
│  🗺 地图  │  📜 故事  │  ⚔ 状态  │  ← 固定底部标签栏
└─────────────────────────────────┘
```

- 默认激活「故事」标签
- 标签切换时使用 Framer Motion `AnimatePresence` 淡入动画
- 三个图标配合文字标签，触摸目标区域 ≥ 44px

### 实现方式

- 修改 `GameLayout.tsx`：用 Tailwind `md:flex` 切换桌面三栏，移动端改为 `flex-col`
- 新增移动端标签状态（`activePanel: 'left' | 'center' | 'right'`）
- 底部标签栏仅在 `< md` 断点显示（`md:hidden`）

**受影响文件：**
- `src/components/layout/GameLayout.tsx`
- `src/components/layout/LeftPanel.tsx`、`CenterPanel.tsx`、`RightPanel.tsx`（添加 `className` prop 支持外部宽度控制）

## 三、属性成长系统

### 角色创建变更

- 移除 ±调整按钮和调整点机制
- 属性完全由职业模板决定（更纯粹的职业定位）
- `CharacterCreate.tsx` 简化为：选择职业 → 确认属性预览 → 开始游戏

### 游戏过程属性成长

- 每章设计 2-3 个关键事件，选择特定选项后获得 +1 属性奖励
- JSON 格式扩展：`grants` 对象新增属性字段：
  ```json
  "grants": { "wisdom": 1, "flags": ["investigated_clue"] }
  ```
- `ActionGrant` 类型扩展，`eventEngine.ts` 中处理属性增量
- `playerStore.ts` 新增 `incrementStat(stat, amount)` action

**成长上限设计（全游戏）：**
- 力量、敏捷、智慧、根骨各最多可获得 +3
- 确保最大属性不超过 12（原类型约束）

**属性来源示例（每章各职业均有成长机会）：**

| 章节 | 事件 | 属性奖励 |
|------|------|---------|
| 第一章 | 成功推理商人死亡原因 | +1 智慧 |
| 第一章 | 力战突破盘问 | +1 力量 |
| 第二章 | 识破毒物成分 | +1 根骨 |
| 第三章 | 追踪成功 | +1 敏捷 |

**受影响文件：**
- `src/pages/CharacterCreate/CharacterCreate.tsx`
- `src/store/playerStore.ts`
- `src/engine/eventEngine.ts`
- `src/types/game.ts`（`ActionGrant` 接口）
- `src/data/events/chapter1.json`、`chapter2.json`、`chapter3.json`（新增成长事件）

## 四、全新职业设计

### 设计原则

1. 天赋**弥补弱点或开辟独特路径**，而非强化已有优势
2. 每个职业至少有 2-3 条专属剧情分支（其他职业无法进入）
3. 所有职业均可通关，但通关路线和体验显著不同
4. 职业名称贴近大唐江湖风格

### 五大职业

#### 1. 捕快（奉旨缉拿）
- **定位：** 官方调查者，代表法度与权威
- **属性：** 力量8 / 敏捷5 / 智慧7 / 根骨4
- **天赋：官威**
  - 效果：可对NPC发动"审讯"选项（无需友好度铺垫），强制获取一条隐藏信息
  - 可开启官方档案室、县衙记录等受限场所
  - 对黑道/暗势力NPC有威慑效果（解锁恐吓对话）
- **专属路线：** 凭官牒正面突破，经由官方渠道接触案件深层信息

#### 2. 道士（玄门行者）
- **定位：** 游方方士，观天地气数
- **属性：** 力量3 / 敏捷5 / 智慧9 / 根骨7
- **天赋：望气观相**
  - 效果：进入新场景自动触发隐藏环境线索描述（无需主动检查）
  - 与NPC对话时能感知对方情绪，显示"[此人似乎有所隐瞒]"等提示
  - 可与其他道士/方士类NPC建立特殊信任关系
- **专属路线：** 通过玄学观察绕过正面审问，以独特视角破解谜题

#### 3. 说书人（江湖口舌）
- **定位：** 走江湖的艺人，消息灵通，能言善道
- **属性：** 力量3 / 敏捷7 / 智慧8 / 根骨4
- **天赋：三寸不烂之舌**
  - 效果：解锁专属"说书劝说"对话选项，可用故事引导NPC自我披露
  - 在茶馆/市井场景获得免费情报（人脉广）
  - 可用"以谣言换谣言"方式获取黑市信息
- **专属路线：** 社会工程学路线，不靠证据靠话术，挑动NPC之间的矛盾

#### 4. 游方医（悬壶济世）
- **定位：** 走方郎中，通晓药理毒性
- **属性：** 力量4 / 敏捷5 / 智慧6 / 根骨9
- **天赋：毒经百草**
  - 效果：完全免疫毒素区域和毒物伤害
  - 可为受伤/中毒NPC施救，换取感恩型隐藏对话
  - 能识别尸体死因中的毒物特征（直接破解第一章死因）
  - 可合成简单药剂作为道具使用
- **专属路线：** 医者仁心路线，以救助建立信任，从医学角度获取线索

#### 5. 飞贼（飞檐走壁）
- **定位：** 江湖上的夜行客，身手敏捷，胆大心细
- **属性：** 力量7 / 敏捷10 / 智慧4 / 根骨4
- **天赋：夜行百盗**
  - 效果：可进入被锁闭或"禁止进入"的区域（翻窗/越墙）
  - 可取得正常途径无法获取的物证（盗取、翻找）
  - 在跟踪/潜行相关事件中自动成功
  - 接触黑市、帮派NPC时有天然亲近感
- **专属路线：** 非正规调查路线，从幕后获取证据，揭示无法通过正面接触得到的真相

### 通关平衡保证

| 关卡类型 | 捕快 | 道士 | 说书人 | 游方医 | 飞贼 |
|---------|------|------|--------|--------|------|
| 审讯NPC | 官威直接 | 情绪感知 | 话术引导 | 医治换信 | 夜探房间 |
| 进入密室 | 官牒开门 | 气感察觉 | 套话问路 | 救人获钥 | 翻窗潜入 |
| 识破骗局 | 调查记录 | 观相识谎 | 以谎攻谎 | 毒物分析 | 偷取证物 |

每类挑战所有职业均有可行路径，但方式完全不同。

## 五、测试要求

所有改动须通过现有 105 个测试用例，并新增：

- **NPC对话修复：** 测试跨章节NPC（npc_wujue）在不同章节对话键互不干扰
- **属性成长：** 测试 `incrementStat` 不超过上限12，存档正确持久化
- **职业平衡：** 每个职业在 conditionEvaluator 中的天赋效果有对应测试
- **移动端：** 视觉回归测试不在此范围内，但需确认组件 props 类型正确
- **提示系统：** 每章至少测试5个关键节点的提示内容不为通用回退文本
