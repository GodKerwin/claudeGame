# 《天机残卷》技术设计规格文档

**版本：** V1.0  
**日期：** 2026-05-27  
**范围：** 第一章完整实现（MVP）

---

## 一、项目定位

武侠 + 文字探索 + 多分支解谜 + RPG 成长类单机前端游戏。

核心体验：**同一个谜题，可以有不同解法**——属性、天赋、门派的差异决定玩法路线。

技术栈：React + TypeScript + Vite + TailwindCSS + Zustand + Framer Motion

## 二、整体架构

### 分层结构

```
┌─────────────────────────────────────────────────┐
│                    React UI Layer                │
│  (场景渲染 / 对话框 / 背包 / 地图 / 操作按钮)      │
└────────────────────┬────────────────────────────┘
                     │ 读/写
┌────────────────────▼────────────────────────────┐
│               Zustand Store (状态层)              │
│  player | currentScene | inventory | flags |     │
│  clues | questLog | saveSlots                   │
└──┬──────┬──────┬──────┬──────┬──────────────────┘
   │      │      │      │      │
   ▼      ▼      ▼      ▼      ▼
story  puzzle  event  map   save
Engine Engine Engine Engine Engine
   │      │      │      │      │
   └──────┴──────┴──────┴──────┘
                 │ 读取
┌────────────────▼────────────────────────────────┐
│              JSON Data Layer (数据层)             │
│  maps/ npcs/ events/ items/ talents/ skills/    │
│  story/                                         │
└─────────────────────────────────────────────────┘
```

### 核心流转逻辑

1. 玩家点击操作 → UI 派发 Action
2. 对应 Engine 读取 JSON 配置，调用 `ConditionEvaluator` 判断属性/标记/背包条件
3. 返回可用选项列表和结果文本
4. 更新 Zustand Store
5. UI 响应式重渲染

### ConditionEvaluator 职责

- 属性门槛：`{ "wisdom": 8 }`
- 背包物品：`{ "has": ["key_001"] }`
- 全局标记：`{ "flags": ["innkeeper_trusted"] }`
- 天赋加成：`{ "talent": "机关奇才" }` 可降低难度阈值
- 标记缺席：`{ "flags_absent": ["already_searched"] }`

### 视觉规范

| 元素 | 值 |
|------|----|
| 背景色 | `#1a1208` |
| 正文色 | `#e8d5a3` |
| 高亮/金色 | `#c9a84c` |
| 危险/死亡 | `#8b1a1a` |
| 字体 | Noto Serif SC（正文）/ 仿宋风格（标题）|
| 面板质感 | 深棕半透明 + 内阴影 + 细金边 |
| 按钮 | 深色底 + 金边，hover 金色发光 |

### 不可用选项处理

灰色显示但保留，hover 时提示缺少条件（`需要智慧 ≥ 8`），让玩家感知"还有别的解法"。

### 响应式

移动端折叠为单列，左右面板变为抽屉式弹出。

## 五、第一章内容大纲

### 主线：长安客栈命案

玩家在客栈二楼客房醒来，发现隔壁商人宋怀义死亡，案发于昨夜三更。  
目标：查明真相，找到《天机残卷》第一条线索。

### 六个地点

| 地点 | 关键内容 | 解锁条件 |
|------|----------|----------|
| 客栈大堂 | 掌柜、醉汉证人、公告板 | 初始开放 |
| 二楼客房 | 尸体、血字、暗格 | 初始开放 |
| 后厨 | 厨娘证词、砒霜痕迹、密道入口 | 与掌柜对话后 |
| 地窖 | 密室入口、四解法机关、残卷碎片 | 获得掌柜信任 |
| 城郊树林 | 逃跑嫌疑人、隐藏NPC「白衣人」 | 发现逃跑线索后 |
| 废弃宅院 | 天机阁旧址、第一章终章剧情 | 集齐三条关键线索 |

### 主线流程

```
醒来发现命案
    │
    ├─ 调查尸体 → 发现血字"天" → 触发线索系统
    ├─ 问掌柜 / 问醉汉 → 获取昨夜异响证词
    ├─ 后厨调查 → 发现砒霜 / 密道
    ├─ 地窖密室（四属性解法）→ 获得残卷碎片一
    ├─ [隐藏] 树林追踪 → 遇见白衣神秘人 → 获得残卷碎片二
    └─ 废弃宅院 → 天机阁旧迹 → 第一章结局
```

### 地窖密室四解法

| 属性要求 | 解法 | 附带效果 |
|----------|------|----------|
| 智慧 ≥ 8 | 推算机关纹路破解 | 无副作用 |
| 力量 ≥ 9 | 强行撞开木门 | 触发 `made_noise` 标记 |
| 敏捷 ≥ 7 | 翻窗潜入 | 触发 `entered_silently` 标记 |
| 根骨 ≥ 8 + 天赋「毒体」| 穿越毒烟 | 触发 `immune_shown` 标记 |

### 第一章结局分支

- **真相路线：** 集齐全部线索，在宅院揭露幕后人是天机阁叛徒
- **莽夫路线：** 力量路线，抓到嫌疑人但放跑幕后人，获得不同后续
- **隐士路线：** 触发白衣人剧情，获得隐藏武学，但主线线索缺失一条

### 第一章隐藏内容

- 隐藏 NPC「白衣人」（触发条件：敏捷≥7 且天黑后探索树林）
- 隐藏武学《无痕步》（白衣人赠予，需通过信任考验）
- 隐藏线索：掌柜李福与天机阁的旧日关联（智慧≥9 且天赋「察言观色」）

## 六、隐藏主线：大飞帮

### 概述

完全隐藏的帮派主线，主线剧情中无任何提示，需玩家自行发现。通过三阶谜题解锁，奖励丰厚，并影响第二章走向。

### 三阶解锁链

**第一层：发现暗号**

- 地点：客栈大堂公告板，一张"失物招领"告示
- 触发：智慧≥6 或天赋【过目不忘】→ 发现落款藏头诗
- 藏头诗提取首字：「大风起兮云飞扬」→ 大、飞
- 奖励：获得线索【残破铜牌】

**第二层：找到接头人**

- 地点：黑市，卖符纸的老头
- 触发：出示铜牌 + 说出暗语「云散见青天」
- 暗语来源：铜牌背面微刻文字（需根骨≥5 屏气细看，或持放大镜道具）
- 奖励：获得地址——废弃宅院东侧枯井

**第三层：通过入帮考验**

- 地点：枯井底部
- 机关：五行锁（数字推理谜题）
- 谜题线索：散落在已收集的三条普通线索文本中（数字暗藏其中）
- 解开后：神秘人「飞爷」现身，邀请入帮

### 帮主「飞爷」

表面身份：走江湖的说书人  
真实身份：昔日天机阁外围成员，知晓残卷部分秘密

### 入帮奖励

- 独特称号「飞帮暗探」
- 专属武学《鬼步连环》（效果等同敏捷+2）
- 大飞帮专属对话选项（多个 NPC 新增隐藏台词）
- 提前解锁第二章地图线索（废弃宅院地图扩展）
- 飞爷提供第三条残卷碎片线索（原本需集齐两条才能进宅院，入帮后可三条全拿）

### 入帮后支线任务

飞爷交代：找到藏在衙门档案室里的一份十年前卷宗，证明宋怀义（死者）并非商人，而是天机阁线人。此线索直接影响第二章主线走向。

## 七、角色创建系统

### 四维属性

| 属性 | 作用 |
|------|------|
| 力量（strength）| 强拆、威吓、重武器 |
| 敏捷（agility）| 潜入、闪避、轻功 |
| 智慧（wisdom）| 解谜、推理、机关 |
| 根骨（constitution）| 抗毒、恢复、内功 |

### 属性分配方式

预设模板选择（4-5个预设）+ 微调（±2点自由分配）。

预设模板示例：

| 模板 | 力量 | 敏捷 | 智慧 | 根骨 | 特色 |
|------|------|------|------|------|------|
| 游侠 | 8 | 7 | 5 | 4 | 力量路线 |
| 谋士 | 3 | 5 | 10 | 6 | 智慧路线 |
| 刺客 | 5 | 10 | 5 | 4 | 敏捷路线 |
| 药师 | 4 | 5 | 6 | 9 | 根骨路线 |
| 全能客 | 6 | 6 | 6 | 6 | 均衡路线 |

### 天赋系统（创建时选一）

| 天赋 | 效果 |
|------|------|
| 过目不忘 | 自动记录关键线索 |
| 机关奇才 | 机关类解谜智慧门槛-2 |
| 天生神力 | 力量类破解门槛-2 |
| 毒体 | 免疫毒雾区域，解锁根骨+毒体专属解法 |
| 察言观色 | NPC对话增加隐藏选项 |
| 江湖老千 | 欺骗与赌博事件成功率+30% |

## 八、存档系统

### 方案

沉浸式触发点（自动存档）+ 隐藏快速存档按钮（兜底）。

### 自动存档触发点

- 进入新地图区域时
- 完成关键谜题时
- 获得重要线索时
- 触发重要对话分支时

### 手动存档

- 场景中触发「歇息」/「写入笔记」等行为
- 隐藏的快速存档按钮（角落图标）

### 存档槽位

- 3个手动存档槽 + 1个自动存档槽
- 存档数据存储于 `localStorage`
- 存档内容：player 状态、当前场景、背包、flags、线索、任务进度

## 十、开发约束

- 单文件不超过 300 行
- UI 与逻辑分离
- 数据与逻辑分离
- 所有事件配置化，禁止写死剧情
- 存档使用 `localStorage`
