# 天机残卷·剧情总大纲

> 本文档依据游戏实际实现（第一至三章）修订，第四至五章为后续开发规划。

---

## 世界观与核心命题

**表层**：一桩发生在长安客栈里的商人谋杀案。

**里层**：一份名单，一个延续二十年的噤声行动。天机阁曾是大唐最深处的庇护网络——它不是朝廷的刺探机构，而是一个人为了兑现承诺秘密建立的。那份名单上的每一个人，都是被某股力量追杀、无处可逃的人，是天机阁创始者亲口答应过要保护的人。二十年前，名单泄露，组织假解散，创始者销声匿迹。如今，有人又开始清算名单上的人，而那个当年让天机阁不得不假死的力量，仍然存在，仍然在等。

**核心命题**：当你握住了足以洗清无数人冤屈的真相，却发现说出它会伤害另一些人时，你会怎么做？

## 核心人物设定

### 飞爷（真名：飞，代号「鸢」）——天机阁创始人

大飞帮帮主，人称飞爷，江湖上以识人用人著称。  
**真实身份**：天机阁创始人，代号「鸢」，建阁之初立下誓言刻于大雁塔旁石碑之上。  
他建天机阁，是为了保护一群被廷尉府旧案牵连、走投无路的人。那份名单，就是他的承诺清单——上面的每一个人，他都亲口答应过会保全。  
**现在的处境**：他知道名单上有人已经被策反，知道幕后那双手是谁，却因为某种只有他知道的缘由选择缄默，在长安藏了二十年，等着一个他信得过的人出现。  
「大飞」二字，是「鸢」的另一种写法——这是他藏在明处的秘密。

### 无迹和尚（真名：韩朔）——天机阁「风字组」联络人

驻守慈恩寺偏院，以采药度日，二十年不离开。  
**真实身份**：天机阁风字组联络人，精通药理，曾参与押运过一批含有砒霜配方的货物。  
二十年前，一次「事故」中右腕受伤，落下旧患。那次事故不是事故——是有人故意安排的，目的是销毁货物、封锁知情人的口。他是幸存者，也是见证者，但他选择了出家，选择了沉默，守着大雁塔旁的那块石碑，等飞爷亲口说出来的那一天。  
他对玩家说的最后一句话：「有些罪，念多少经都还不清楚，只有说出来，才能真正还。」

### 李邈——天机阁旧部之子，浪鹏帮幕后指挥

皇城茶馆的常客，身份模糊，行事谨慎。  
**第一章真实身份**：往事客栈里出现的「白衣人」——他提前到达客栈，评估宋怀义的处境，也在评估玩家。  
**真实动机**：他掌握着一部分天机阁的旧档，在幕后指挥浪鹏帮追索名单。但他自己也只是个传话的棋子——发令的那个人，在他之上，他知道，却没说出来。  
关键台词：「名单的事，比你看到的要深得多。宋怀义死了，但那份名单背后的人还在——而且，在等。」

### 掌柜李福——天机阁「驿」，长安最后一枚活棋

往事客栈掌柜，开店十年，平日油滑，实则沉稳。  
**真实身份**：天机阁埋在长安的驿站人员，专职情报中转，以客栈为掩护。  
宋怀义死前，曾向他说出一句话——李福将这句话藏在心里，等着一个他认为「合适的人」来问。那个合适的人，就是玩家。

### 宋怀义（亡者）——名单上的人，不是叛徒

案件的死者，表面上是个往来长安的商人。  
**真实身份**：天机阁保护名单上的人，二十年前因某件事对飞爷产生了不信任，带着名单出逃。  
他来长安，是为了回来——他发现了名单上有人被策反，想亲口告诉飞爷，却在名单交接前被杀。  
他不是叛徒，他是一个在错误的时间做了正确决定、却没能活着说出来的人。

## 第一章：长安城·往事客栈

**已实现。**

**核心谜题**：商人宋怀义死于密室，双重手法——毒茶致昏，再遭勒毙。凶手走密道入室，翻窗越墙而出，留下「鸢」字信物与天机阁名录碎片。

**关键地点**：往事客栈（room_203 / 大堂 / 后厨 / 地窖 / 废弃宅院 / 城郊树林 / 后巷）

**主要人物行动**：
- 李福识出「天机」令牌，藏在油滑掌柜面具后的震动无法掩盖
- 白衣人（实为李邈）在树林出现，评估玩家深度；赠「无痕步」，说「你查案的方式让我想起一个故人」
- 飞爷在废弃宅院的密室现身，说宋怀义是天机阁旧日线人，「叛变后带走了一份关键名单，有人为此等了他十年」——这句话有一处关键的不精确，是飞爷刻意省略的部分
- 地窖与废弃宅院的调查最终指向：宋怀义来长安，是为了交接，不是为了逃

**章末揭示**：宋怀义死于两双手——毒茶是一人的安排，勒毙是另一人补刀。凶手不止一个。「鸢」字密信与鸢组旧档指向某个与天机阁深度关联的结构。

**悬念钩子**：白衣人是谁？飞爷说宋怀义「叛变」，但李福的表情里有另一种意思。杀他的第二双手，属于谁？

**三种结局**：
- `chapter1_truth_ending`：还原双重手法与动机，指出背后名单的走向
- `chapter1_force_ending`：以武力强行结案（strength ≥ 8）
- `chapter1_hermit_ending`：跟随白衣人，习得无痕步，选择置身事外

## 第二章：长安城·暗渡陈仓

**已实现。**

**核心谜题**：追查名单与凶手线索至长安东市，无迹和尚浮出水面，白衣人的身份被确认。

**关键地点**：东市入口 / 回春堂 / 西市古玩铺 / 慈恩寺偏院 / 平康坊据点 / 皇城茶馆 / 廷尉府外街

**主要人物行动**：

**无迹和尚的层层揭开**  
玩家在慈恩寺找到无迹和尚，他识得大飞帮令牌，坦承认识药方：「砒霜配曼陀罗，是天机阁当年的配法，在下是当年的知情者之一。」  
进一步逼问，他才说出真名：「韩朔，天机阁风字组。那是二十年前的事了。」  
守碑二十年的原因，他在第三章才说完整。

**李邈的正面交锋**  
皇城茶馆，白衣人摘下伪装，承认指挥浪鹏帮：「浪鹏帮是我雇的，任务是盯梢和截件，不是杀人。宋怀义死的那一夜，我的人还在客栈外守着，根本没有机会进去。」  
他将浪鹏帮的失控归结为棋子不受控——但他随即说出了真正重要的一句话：  
「我也不过是颗棋子。发令的那个人，不是我。」  
他给出天机阁长安据点的暗号：「归鸟问津」——这是第三章的入口。

**章末揭示**：无迹和尚二十年前的「事故」不是意外；廷尉府外街的档案里有旧案影子；李邈之上还有一双手在等待。宋怀义的死，是一笔被多方同时押注的旧账。

**三种结局**：
- `chapter2_arrest_ending`：逮捕李邈，案件移交廷尉府——但更深的那层，没有动
- `chapter2_release_ending`：放走李邈，保留线索，独自继续追查
- `chapter2_join_ending`：接受李邈的招募，从内部接近天机阁残部

## 第三章：长安城·鸢归何处

**已实现。**

**核心谜题**：顺着「归鸟问津」的线索，在长安旧地追查飞爷的真实身份，发现名单背后真正的意义。

**关键地点**：大雁塔下 / 天机安宅 / 飞爷故居 / 曲江亭 / 乐游原 / 廷尉府外院 / 天机旧宅·故地

**主要人物行动**：

**无迹和尚说完那句话**  
在大雁塔旁的石碑前，他守了二十年，对玩家说出立碑者的名字：「他叫飞，代号鸢，是天机阁的创始之人。飞爷当年建天机阁，是为了护那份名单，护名单上被廷尉府追杀的人。宋怀义也在其中。」  
他最后说：「贫僧守了二十年的秘密，终于有人替它开了口。」

**飞爷在曲江亭**  
他没有逃跑，他在等。  
「鸢，对，是我。二十年前给自己起的代号，现在要拿来跟你解释了。……你想听实话，还是想先拿住我？」  
他承认：名单上的那些人，是被廷尉府追杀的人，他逐一答应过要保护；宋怀义离开是因为「他不信任我了」——但为什么不信任，飞爷没有说完。  
关于「更上层的那个人」，他说：「我知道他是谁。我选择不说出来，不是因为怕，是因为他也在保护一些人。那些人，我暂时动不了他。」  
这句话留下了第四章的核心悬念。

**天机联络人的警告**  
「还有一双眼睛，在我们之上——他们比天机阁更早知道名单的存在，比浪鹏帮更安静，比李邈更有耐心。你去见飞爷，要有这个准备：那双眼睛，也在等着飞爷开口的那一刻。」

**章末揭示**：飞爷是鸢，名单是承诺，廷尉府是猎人。但名单上有人已经被策反——无迹和尚的最深秘密：「二十年前那次事故……不是事故。那个人，至今还在长安。」

**三种结局**：
- `chapter3_truth_ending`：将飞爷的真实身份与名单的性质整理成案，提交廷尉府可信层级
- `chapter3_standoff_ending`：与飞爷达成协议，各守一段真相，等待时机
- `chapter3_join_ending`：（需 chapter2_join_ending）加入天机阁，成为飞爷等待的那个人

## 第四章：长安城·归鸟问津（规划中）

**核心谜题**：李邈说过「发令的那个人在我之上」，天机联络人说过「有一双眼睛在我们之上」，飞爷说过「我知道他是谁，我选择不说」。第四章，这三句话指向同一个人。

**主题**：二十年的噤声 / 幕后者的面目 / 宋怀义为什么不信任飞爷

### 新角色登场

**宋清月**（宋怀义之女）  
父亲死后，她从南方一路追查，独自追到长安，走的是另一条线——不是跟着天机阁的痕迹走，而是跟着父亲最后的行踪走。  
她来找的不是名单，而是父亲临死前想说出来却没来得及说的那件事。  
她不认识飞爷，也不知道天机阁，她只知道父亲临终前反复提到一个字：「鸢。」  
她的到来，给玩家提供了一个飞爷视角以外的叙述——一个被保护者的孩子，如何看待「保护」这件事。

### 主线事件

**事件一：「归鸟问津」深处**  
以第二章李邈给出的暗号为入口，玩家进入天机阁在长安的真正核心网络。这里仍在运转——有联络人，有档案，有等待消息的人。  
但网络内部气氛异常：有人知道「名单上有内鬼」，但没有人知道是谁。这个秘密导致内部彼此不信任，都在等待指令，都不敢行动。  
这就是飞爷「不说那个人」的代价——保护了幕后者，也让自己人陷入瘫痪。

**事件二：宋清月与父亲的信**  
玩家在某处遇到宋清月，她带着父亲留下的最后一份字迹——不是密信，不是账本，是一张写了一半、没有写完的便条：  
「吾儿，若你看到此信，说明父亲没能回来。我来长安，不是为了别的。我发现名单上有一个名字不该在那里，而那个人，正是——」  
便条在这里断了。  
**反转**：宋怀义带走名单，不是因为他背叛了天机阁，而是因为他发现名单被篡改过——有人悄悄替换了几个名字，把无辜的人换进去，把真正有罪的人的名字删掉。他要把这个消息告诉飞爷，但他不敢走内部渠道，因为内鬼就在里面。  
他来长安，是为了当面把这件事说给飞爷听。他在被杀的前一刻，还没有找到飞爷。

**事件三：二十年前的那次事故**  
无迹和尚的旧伤牵出当年真相。  
二十年前，天机阁的一批货物在押运途中「出事」——货物被销毁，经手人一死一伤（死者就是名单上的某个人，伤者就是韩朔）。当时的廷尉令认定是「运途失事」，结案。  
但那次事故，是有人提前通报了押运时间和路线——只有知道内部安排的人才能做到这一点。  
那个人，就是幕后者。他在二十年前就已经开始清理与自己有关的所有痕迹。

**事件四：幕后者现身——薛崇礼**  
**薛崇礼**：前廷尉令，现任太子少保，名义上已「告老在家」，实则仍通过旧部控制廷尉府的特定案档。  
史书和朝野对他的评价是：「治世名臣，执法公允」。  
真相：二十年前，他在廷尉府内与某北境势力秘密往来，将大唐边境情报换取政治庇护。天机阁在无意中掌握了这份往来证据，并将它藏在了名单里——名单上不只有人名，也有案卷附录。  
飞爷知道这件事，但薛崇礼也掌握着飞爷某些旧日行为的把柄。  
两人二十年的噤声，是一场不说话的对峙。

**章末反转**：  
玩家将所有线索汇总——篡改名单的人，是薛崇礼安插在天机阁内部的棋子。这枚棋子的身份，玩家在前几章一定见过。  
便条上那个断在一半的名字，宋清月记得父亲的笔迹，她把断掉的字补全：是「谢」字开头的某个人。  
「谢」——是天机联络人在归鸟问津据点里行事时用的化名。

## 第五章：长安城·天机再动（规划中）

**核心谜题**：薛崇礼的罪证已在手中，名单的真相已拼全，所有人汇聚长安。但证据本身是一把双刃剑——递交朝廷，会动摇超过二十年的朝局；销毁它，宋怀义死得不明白，名单上的人继续活在不知道的危险里。

**主题**：没有完美的正义 / 你如何处置一个已经无法更改的真相

### 主线事件

**事件一：四方汇聚**  
飞爷、无迹和尚（韩朔）、宋清月、李邈（无论前两章结局如何，他都以某种方式出现），加上玩家，在往事客栈的某处秘密集合。  
每个人对证据的看法不同：

- **飞爷**：「把它交给一个我信得过的人。我在这座城里等了二十年，就是为了找到那个人。」——他指的是玩家，但这句话有前提
- **宋清月**：「我不在乎朝廷怎么处置。我只要父亲的名字从「叛徒」的名单上消失。」
- **无迹和尚（韩朔）**：「贫僧守了二十年，守的不是秘密，是赎罪的机会。」——他愿意出面作证，为当年的事故担责
- **李邈**：取决于前两章走向；若他自由，他会说「我只想离开这座城市」；若他被逮捕，玩家需要想办法

**事件二：往事客栈的最后秘密**  
李福终于说出宋怀义临死前找他说的那句话：  
「宋怀义说：『名单里多了一个「谢」字开头的人。这个名字不该在里面。谁放进去的，就是那个坏了事的人。你把这话告诉……』」  
他没说完，被人打断了。李福保守这句话十年，因为他不知道该告诉谁，也不知道「谢」字是谁。  
现在玩家知道了。

**事件三：薛崇礼的应对**  
薛崇礼不会坐以待毙。他通过旧部在廷尉府发动最后一次清档行动——试图销毁自己名下的所有旧案记录。  
同时，他向飞爷传话：「二十年了，你我都知道放开这件事意味着什么。这最后一步，你确定要走？」  
飞爷沉默了很久。然后他转向玩家，说了第五章里最关键的一句话：  
「你来找我，说明你已经走到了最后。剩下那一步，是你的，不是我的。」

**事件四：最终抉择**  
玩家手中同时握有：
- 薛崇礼与北境往来的旧案证据（天机阁档案残页）
- 名单的修复版本（宋怀义发现的篡改痕迹）
- 无迹和尚（韩朔）愿意出面的证词
- 宋清月关于父亲的证词

四种结局，没有完美答案：

## 终章多结局

### 结局一：付诸一炬

玩家将所有证据销毁——薛崇礼的把柄，天机阁的档案，名单的一切。  
薛崇礼安然活着。宋清月的父亲仍是「叛徒」。  
飞爷在曲江亭坐了很久，什么都没说。  
宋清月离开长安前，在往事客栈的墙上刻了一行字，没有署名。李福每天路过，不去擦它。  
**尾声**：多年后，有人在旧档里发现一条记录被人篡改过，那个「谢」字的名字被描掉了，改成了一片空白。没有人知道是谁做的。

### 结局二：托付明人

玩家将名单修复版与薛崇礼的罪证，秘密递交给一位仍可信任的官员（由游戏中建立的信任关系决定此人）。  
薛崇礼被查，案件以「旧事重提」之名低调处置，族中受罚，本人在软禁中度过余年。  
宋怀义在一份补发的驿站档案里，被更正为「殉职线人」，不再是叛徒。  
**尾声**：那位官员退休前，将所有文件原封不动地封入一个漆匣，交给了某处无名的档案库。他说：「留给后人。这件事太重，我一个人压不住。」

### 结局三：公之于众

玩家以碎片化的方式，将真相散布入坊间——不是一份完整的控告，而是足够让人开始怀疑的线索。  
薛崇礼在流言中被弹劾，最终以「年迈致仕」之名退出朝堂，真相悬而未决。  
宋清月以「浪王」之名在江湖中流传父亲的故事；飞爷在某一天忽然解散了大飞帮，原因不明。  
**代价**：天机阁在清洗中再次销声匿迹。  
**尾声**：往事客栈三年后换了掌柜，新掌柜在地窖里发现了一枚刻着「驿」字的玉牌，以为是前任落下的杂物，随手收了起来。

### 结局四：天机再启（隐藏结局）

需要条件：chapter3_join_ending + 收集全部核心线索 + 飞爷信任满级

玩家与飞爷一同，以修复后的名单为基础，重建天机阁——不为任何人效力，只为那些仍然走投无路、无处可去的人。  
韩朔（无迹和尚）脱下僧袍，重新用回旧名。宋清月在犹豫之后选择加入。  
薛崇礼的证据被保存，作为将来的后手——不是要用它，而是不让它消失。  
**尾声**：往事客栈收到一封无名信，信上只有四个字：「天机再动。」  
李福在柜台后面看了那四个字很久，把信叠好，放进了贴身的内袋里。这一次，他不打算等下一个合适的人——他知道那个人已经来了。

## 支线剧情提要

### 支线：宋清月与父亲的选择（第四章起）

宋清月一路追来，始终有一个问题没有答案：父亲为什么不逃，而是回头来长安？  
当她终于从玩家口中得知父亲是为了揭露内鬼、为了保护天机阁里其他人，她沉默了很久。  
然后她说：「他本可以跑的。他选择回来，就是知道回来意味着什么。」  
支线结尾有三个走向：
1. 她选择用父亲的遗愿作为告别，不再追究，离开长安
2. 她选择出面作证，用自己的名字为父亲翻案——哪怕这会让她暴露
3. 她和飞爷谈了一次长话，内容玩家不完全知道，只知道谈完之后，飞爷第一次在某人面前低了头

### 支线：韩朔的赎罪

二十年的佛经，是为了他没有阻止那次「事故」的自责。  
支线的核心问题：一个人如果当年没有勇气开口，用二十年的沉默能还清吗？  
三个走向：
1. 他出面作证，承担在押运事故中知情却未言的责任，以此换取其他人的豁免
2. 他选择继续沉默，守着碑，但在玩家离开长安后，将「韩朔」三个字刻在了碑的背面
3. 他和飞爷在慈恩寺说了二十年里第一次真正意义上的道别

### 支线：李福与往事客栈的前世

分散在各章节的碎片，可以拼出客栈的真实历史：  
它原名「归尘驿」，是天机阁在长安最早设立的中转站，有一百年历史。  
「往事」二字是李福改的，就在天机阁假解散的那一天。  
他说：「留这两个字，是提醒自己——有些事是往事，有些事不是。」  
这条支线的结尾，会告诉玩家李福等了十年等的到底是什么，以及他为什么选择了玩家。

### 支线：飞爷与薛崇礼的二十年对峙

两个人互相握着对方的把柄，二十年没有动手，也没有和解。  
这条支线的核心问题：一个人可以为了「保护别人」忍受多久？当他终于不需要再忍的时候，他选择的是什么？  
飞爷的答案，在第五章结局中，由玩家的选择来决定。

## 关于「大飞帮」之名

「大飞」二字不是江湖绰号，是创始人姓名「飞」与代号「鸢」（会飞的东西）的组合。  
这是藏在最明处的秘密——长安城里每一个知道大飞帮的人，都叫过「大飞帮」这三个字，却没有人往深处想。  
无迹和尚在大雁塔下守碑二十年，守的碑上刻着那个创始人的名字。每当有人从寺门外经过，喊一声「大飞帮」，他就在心里默默念一遍碑上那个字。
